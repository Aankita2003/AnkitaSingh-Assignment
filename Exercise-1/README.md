# Medical & Travel Expense Request

A responsive web application that recreates the **Medical & Travel Expense Request** form from the provided PDF using **HTML, CSS, and JavaScript**. The project closely follows the original design while incorporating dynamic functionality and a clean, user-friendly interface.

---

## 📌 Project Overview

The objective of this project was to recreate the given PDF form as a responsive web page using only HTML, CSS, and JavaScript. The application dynamically generates sections of the form and maintains a layout similar to the original document.

---

## ✨ Features

- Responsive design for different screen sizes
- Dynamic generation of expense tables using JavaScript
- Clean and structured user interface
- Form validation
- Submit and Reset functionality
- PDF-inspired layout and styling
- Organized project structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
