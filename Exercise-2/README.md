# Worker Progress Report

A responsive web application that recreates the **Worker Progress Report** form from the provided PDF using **HTML, CSS, and JavaScript**. The project closely follows the original document while implementing interactive form validation and user-friendly functionality.

---

## 📌 Project Overview

This project recreates the Worker Progress Report PDF as a responsive web page. It includes form validation, interactive controls, and a clean interface using HTML, CSS, and JavaScript.

---

## ✨ Features

- Responsive design
- PDF-inspired layout
- Input validation
- Required field verification
- Checkbox validation before submission
- Submit and Reset functionality
- Success message after submission
- Clean and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
